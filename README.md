# Claim 知识图谱流水线（连续七轮）

完整复制本目录到一个新任务文件夹，仅向 `data/` 放入：一个 `核心文献*篇.jsonl`、`文献主表.jsonl`、`参考文献关系-原始.jsonl`。保持JSONL字段格式；数量以核心文件内容为准，其他两表可包含外围记录。

给新Agent发送 `启动提示词.md` 的提示词。核心规范位于根目录 `PIPELINE_AGENT.md`；Agent负责输入核查、领域配置、七轮科学生成与检查，用户无需改代码。安装依赖用 `python -m pip install -r requirements.txt`，运行入口为 `python pipeline.py`。

七轮：输入规范化 → 隐藏引用骨架 → 标题摘要Claim生成 → Claim独立复核与稳定ID → 领域配置和多通道候选 → 规则初判及Agent定点复核 → SVG/机器图装配与验收。

本版本默认连续执行：发送一次 `启动提示词.md` 后，Agent 会从初始化持续完成七轮，在每轮内部完成真实 Agent 工作、检查、修订、校验和留痕，不要求用户逐轮输入“继续”；仅在出现无法自行安全解决的真实阻断时暂停。最终文件位于 `知识图谱构建过程/07_图谱装配/`。模板 `data/` 为空，无任何论文、Claim 或关系答案。

工具维护验证：`python -B tests/test_pipeline.py`，全部合成内容在系统临时目录生成，不会写入本项目 `data/`。
